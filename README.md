# Real Estate Management System

A comprehensive web-based platform for managing real estate properties, agents, and user interactions.

## Overview

This Real Estate Management System is built to streamline property listings, agent management, and user interactions in the real estate business. It provides separate portals for different user types with distinct functionalities and permissions.

## Features

✨ **Multi-User System**
- **Admin Portal** - Manage agents, users, and system settings
- **Agent Portal** - List properties, manage client relationships
- **User Portal** - Browse properties, make inquiries and save favorites

🏠 **Property Management**
- Add and manage property listings
- Upload property details and images
- Track property status and availability

👥 **User Management**
- Role-based access control (Admin, Agent, User)
- Secure authentication and authorization
- User profile management

📊 **Dashboard**
- View statistics and analytics
- Track activity and interactions
- Manage inquiries and leads

## Tech Stack

- **Backend**: PHP
- **Frontend**: CSS, JavaScript
- **Version Control**: Git

## Getting Started

### Prerequisites
- PHP 7.0 or higher
- Web server (Apache, Nginx, etc.)
- Database (MySQL/MariaDB)

### Installation

1. Clone the repository
   ```bash
   git clone https://github.com/nadim249/Real_Estate_Management_System_Webtech_Final_group_9.git
   cd Real_Estate_Management_System_Webtech_Final_group_9
   ```

2. Configure your web server to serve the project root

3. Set up the database and configure connections

4. Access the application through your web browser

## Usage

- **Admins**: Login to the Admin portal to manage users and system settings
- **Agents**: Access the Agent portal to create and manage property listings
- **Users**: Browse properties and make inquiries through the User portal
